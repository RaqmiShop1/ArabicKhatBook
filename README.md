# ArabicKhatBook
برنامج Windows للمعلمات والمعلمين وأولياء الأمور: اكتب أي كلمات أو جمل — كلمات الإملاء، آية، اسم الطفل — فيولد كراس تدريب خط PDF بحروف منقطة على مسار القلم يتتبعها الطالب، بمستويات تدرج تربوية (تتبع ثم توجيه ثم كتابة حرة) ومسطرة رباعية تعليمية. يشمل وضع «تأسيس الحروف» بكلمات مواضع الحرف الثلاثة، والأقوى: الصق أسماء الفصل من Excel فيخرج كراس مستقل باسم كل طالب وتدريب على كتابة اسمه. كل شيء على جهازك دون إنترنت.
